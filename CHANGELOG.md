## [0.1.0] - 2026-03-17

### Added
- Local semantic search engine with fastembed ONNX backend
- SQLite storage for portable index management
- Incremental indexing for efficient updates
- Smart chunking with configurable strategies
- 4 MCP tools for agent-driven semantic search
- 74 tests with full coverage
